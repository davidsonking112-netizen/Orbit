# Orbit — AI workspace UI prototype

A responsive React/Vite front-end prototype inspired by the Orbit design mockups. It includes schedules and automations, a file library, integrations, settings, and a running-task conversation view.

## Run locally

```bash
npm install
npm run dev
```

The screens are a visual prototype: schedule creation, integration states, file actions, and preferences use local UI state only. They are not connected to real services or persistent storage.
